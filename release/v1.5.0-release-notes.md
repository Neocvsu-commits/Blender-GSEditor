# GS Editor v1.5.0

发布日期：2026-11-18

## 本版更新

- 新增框选、套索、多边形、笔刷四种选择方式，支持表面/穿透、替换/加选/减选。先形成选区，再统一擦除。
- Blender 5.3 原生点云与 Blender 共用选区，可继续使用原生全选、反选、变换；高斯选择工具加入左侧工具栏。
- 移除重复的圆形刷选入口，旧配置自动迁移到笔刷选点；Blender 原生圆选仍可使用。
- 笔刷统一为「选点 / 涂抹 / 还原 / 覆盖」四种功能。作用范围、选择操作分行，参数就地显示，执行按钮位于参数下方。导出独立，低频功能保留在高级工具。
- 优化百万级点云笔刷的候选点缓存和选区同步，松手提交完整结果；擦除仅读取所需属性。修复 Blender 5.3 Float4 属性读取报错。
- 保留 Blender 4.2+ 的高斯建模参考显示与参考对象选区；包围盒显示避免视口叠加密集网格顶点。

## 安装包

- Windows：`gs_editor-1.5.0-windows.zip`
- macOS：`gs_editor-1.5.0-macos.zip`（目标为 Apple 芯片，尚未实机验证）

两份 ZIP 使用相同的纯 Python 源码，按平台后缀方便分发。在 Blender「偏好设置 → 获取扩展 → 从磁盘安装」选择对应 ZIP。升级前保存工程，升级后重启 Blender。

Blender 4.2+ 提供建模参考模式；原生高斯编辑要求 Blender 5.3+。旧的 5.3 原生点云需先导出标准 PLY，才能在 LTS 中作为参考导入。

## 验证与限制

- Windows Blender 5.3.0 Beta 的四种选择、表面/穿透、原生选区联动、编辑模式擦除、旧配置迁移和最终界面绑定已做定向检查；最终界面已由使用者确认。
- 此前 Windows 4.2.22 的参考显示、叠加层、参考选区与擦除检查通过；本次以 5.3 为主测试版本。未执行完整鼠标端到端回归，4.5 LTS 与 macOS 尚未实测。
- 300 万点模拟 CPU 对比中，12 段笔触平均计算从 86.55 ms 降到 3.31 ms，索引准备约 25.33 ms。该数据不含投影、Blender 数据刷新及 GPU 显示，不代表实际视口帧率。
- 表面选择按当前对象高斯中心的屏幕格最近深度近似筛选，不检测其他网格遮挡；Blender 原生点云选择按穿透工作。
- LTS 参考模式仅用于视口建模参考，不参与 F12 渲染，不开放原生笔刷还原、覆盖和 PLY 导出。
