GS Editor 1.4.1 增加 Blender 4.2+ 的高斯建模参考模式，并修正叠加层下密集顶点遮住高斯的问题。

## 本次更新

- 新导入的参考对象默认使用「显示为：边界范围」。启用插件、重开文件、撤销或重做时，也会为已有参考对象应用该设置。无需关闭网格线、坐标轴等视口叠加层，高斯数据保持不变。
- 增加标准 3DGS PLY 导入，支持 ASCII、二进制小端和大端，以及 Y/Z 朝上轴选择。
- 增加独立视口高斯显示、基础颜色、透明排序、网格深度遮挡、参考不透明度与显示点数上限。
- 高斯数据随 .blend 保存，重新打开时启用插件即可，不依赖原 PLY 路径。
- 修正 Blender 插件注册阶段访问场景数据的限制，已有对象的显示迁移延后到注册完成后执行。
- 保留 Blender 5.3+ 原生擦除、还原、覆盖功能；包含当前源码中的 PLY/GLB 导出朝上轴选择，两种输出使用同一坐标系。

## 下载与安装

- Windows：gs_editor-1.4.1-windows.zip
- macOS：gs_editor-1.4.1-macos.zip

两个包包含相同的纯 Python 插件代码，后缀用于区分下载入口。Blender → 偏好设置 → 获取扩展 → 从磁盘安装，直接选择 ZIP。升级前保存工程，安装后重启 Blender。

## 兼容性与验证

- Blender 4.2+：建模参考模式；原生高斯编辑仍需 Blender 5.3+。
- Windows Blender 4.2.22：已用约 26 万点的真实 PLY 检查视口显示及开启叠加层后的显示。注册、已有对象显示迁移、注销检查通过；PLY 三种编码读取与 .blend 数据保存恢复已有定向检查。
- Blender 4.5 LTS、macOS Apple 芯片：兼容目标，尚未实机验证。
- 本次只进行针对性检查，没有重跑旧版完整功能自检。

## 已知限制

参考模式不参加 F12 渲染，不提供原生高斯擦除/还原/覆盖/PLY 导出；高阶视角颜色仅保留数据，暂不计算显示。参考对象不是重建表面，不能直接用于面吸附、Shrinkwrap 或布尔。暂不读取 SPZ 或压缩 PLY。

早期离屏检查曾得到空图像，实际视口显示已经确认，离屏检查原因未定位。开发期间热重载后切换编辑器曾触发 Blender 崩溃，原因未确认；请通过保存工程后重启 Blender 完成升级，不在工作场景中热重载。
