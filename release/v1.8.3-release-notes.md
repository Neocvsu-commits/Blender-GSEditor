# GS Editor v1.8.3

发布日期：2026-11-28

## 相比 v1.5.0

- 新增 SOG、SPZ、Splat、LCC、LCC2 导出，保留标准 PLY；LCC / LCC2 支持空间分块和多级 LOD，导出整包 ZIP。
- 所有格式遵从导出窗口的 Y / Z 朝上设置；位置、旋转和高阶球谐一起转换。压缩转换在后台执行，可取消，失败时保留原目标文件。
- 移除覆盖面片及附带 GLB 导出，笔刷集中为「选点 / 涂抹 / 还原」；已有场景中的面片仍作为普通网格保留。
- 增加当前模式状态和「返回物体模式 / 编辑高斯」按钮，修复 Tab 被选择工具拦截及退出后工具残留的问题。
- 修复插件启用期间访问受限场景导致工具注册中断、编辑模式无法切换工具或作用范围的问题。
- 优化大点云重复选择和长套索计算，保持完整点云、原轮廓及 Blender 原生选区联动。

## 下载与安装

- Windows x64：`gs_editor-1.8.3-windows.zip`
- macOS Apple Silicon：`gs_editor-1.8.3-macos.zip`
- 文件校验：`gs_editor-1.8.3-SHA256SUMS.txt`

在 Blender「偏好设置 → 扩展 → 从磁盘安装」中选择对应 ZIP。升级后请保存工程并重启 Blender。
两个包包含相同源码和双平台 WebP 编码器，以文件名后缀区分分发平台。
Blender 4.2+ 提供建模参考模式；原生高斯编辑和多格式导出要求 Blender 5.3+。

## 验证与限制

- Windows Blender 5.3 Beta 已完成相关定向检查，包括受限启动注册、工具及作用范围切换、模式退出、导出编码和选区一致性；Windows 4.2.22 的建模参考显示已验证。4.5 LTS 和 macOS 尚未实机验证。
- 2359267 点合成基准：同视角索引准备 304.45 → 11.10 ms；128 顶点套索 150.70 → 66.59 ms。选区逐位一致，144 组边界对照及缓存失效检查通过。
- 首次选择或视角、模型变化仍需重算，本次首次索引约 290 ms。上述数字是后台计算时间，不代表视口帧率。
- LCC / LCC2 的网页优化需要查看器实际支持对应格式、LOD 调度和分块加载；粗层为近似合并，不承诺与其域相同画质。
- 安装包保留 GPL、上游来源、WebP 及 XGRIDS 格式声明，详见 LICENSE、NOTICE.md 和导出包内的 FORMAT_NOTICE.txt。
